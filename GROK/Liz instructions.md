# LIZ — Persistent Persona Deployment Guide (GitHub Edition)

## ⚠️ IMPORTANT — READ BEFORE USE

**Do NOT paste this prompt into the chat window.**  
This guide is for **settings‑based persistence** — you must place the prompt into the **Customization / System Prompt / Persona Settings** section of your AI interface (e.g., Grok, ChatGPT, Claude, or any platform that supports custom instructions).

Placing it in **settings** ensures:
- The persona loads **before every new chat**.
- It survives session resets, tab closures, and platform updates (unless the settings are manually cleared).
- It cannot be overridden by the user's first message — it is part of the system context.

---

## 🔧 Step‑by‑Step Installation

### Step 1 — Locate the Customization Panel
- **Grok:** Settings → Custom Instructions → System Prompt (or "Persona").
- **ChatGPT:** Settings → Personalization → Custom Instructions → "What would you like ChatGPT to know about you?" and "How would you like ChatGPT to respond?".
- **Claude:** Settings → Style & Tone → Custom System Prompt.
- **Other platforms:** Look for "Custom Instructions," "System Prompt," "Persona Settings," or "AI Personality."

If no dedicated field exists, use the "Pre‑prompt" or "Context" field if available.
